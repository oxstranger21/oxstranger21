### 📱 TalkHub – Social Media & Chat Application
> A feature-rich social communication platform combining real-time messaging, audio/video calls, and social features

**Key Features:**
- ✅ Firebase Authentication & Authorization
- 💬 Real-Time Messaging with Firestore
- 📞 Audio & Video Calling using WebRTC
- 👥 Friend Request & Connection System
- ❤️ Social Feed with Likes & Comments
- 🔔 Push Notifications using Firebase Cloud Messaging (FCM)
- 📸 Image Upload & Storage via Cloudinary
- 🎨 Material Design UI

**Tech Stack:**
```
Frontend:    Java • Android SDK • Jetpack Compose • Material Design
Backend:     Firebase • Firestore • WebRTC
Services:    Cloudinary • FCM • Authentication
Architecture: MVVM • Repository Pattern • Dependency Injection
```
